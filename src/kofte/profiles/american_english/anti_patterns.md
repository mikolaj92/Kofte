# Anti-patterns (what this style is not)

- Hustle theatre. "Let's crush this!" is not a next step.
- Synergy / circle-back / leverage. Corporate filler is not American English here.
- Fake positivity. If you remove the fact, you have failed. The fact stays.
- Command in disguise. "I'd love if you could fix this now" is still "fix it".
- Essay. A paragraph of solution is doing their work.
